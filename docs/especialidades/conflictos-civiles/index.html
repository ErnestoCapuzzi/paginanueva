PARA EL PRIMER ENCUENTRO

Qué podés
tener a mano.

No hace falta que tengas todo resuelto para consultar.

  • Una cronología breve de los hechos.
  • Comunicaciones y documentación relacionadas.
  • Notificaciones recibidas y sus fechas, si existen.
  • No compartas documentos ni datos sensibles a través de esta demo.
